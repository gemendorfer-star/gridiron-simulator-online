TEAM STRENGTH UPGRADE
Upload the files in this ZIP to the root of your existing GitHub repository. New file: team_quality.py. Updated files: mobile_server.py and index.html. The other files are included for completeness.

The model now fetches completed games for the selected season and adds a modest record/schedule adjustment to its existing recent-scoring, player and injury adjustments. Team record, scoring averages, last-five win rate, and available opponent win percentage appear in simulation details. No fabricated data if feeds are missing. This is a heuristic and has not been validated for predictive accuracy.

Live ESPN feed and Render deployment were not tested in this environment.
