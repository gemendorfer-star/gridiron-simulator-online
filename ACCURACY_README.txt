GRIDIRON SIMULATOR — HISTORICAL ACCURACY UPDATE

WHAT IS NEW
- A historical accuracy tracker at the bottom of the mobile webpage.
- Compares pregame team-form baseline picks with completed historical ESPN game scores.
- Counts games evaluated, correct winners, incorrect winners and shows game-level outcomes.
- Historical testing uses only each team's games completed before its prediction.

IMPORTANT LIMITATIONS
- This is NOT a backtest of the full live Gridiron Simulator prediction model.
- Historical starter/injury data are not reconstructed. No validated strength-of-schedule adjustment.
- Home-field adjustment is an assumed 2.2 points, not a fitted coefficient.
- A historical baseline accuracy percentage must not be advertised as the live model's accuracy.
- Data feed availability may vary; the accuracy panel reports unavailable weeks.
- This tool is not a betting recommendation or guarantee.

INSTALL
1. Open the existing GitHub repository gridiron-simulator-online.
2. Add the NEW accuracy_tracker.py file at the repository root.
3. Replace index.html and mobile_server.py with these versions.
4. Keep all other files as-is; this ZIP includes them for convenience.
5. Commit the changes. Render auto-deploys if enabled; otherwise use Manual Deploy.
6. Wait until Render shows Live, refresh Safari, and scroll to Historical accuracy tracker.

Your Windows V18 app is not affected.
