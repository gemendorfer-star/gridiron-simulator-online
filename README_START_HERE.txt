GRIDIRON SIMULATOR - FREE ONLINE IPHONE VERSION

Your Windows V18 folder is not changed.

1. Unzip this folder.
2. Create a GitHub account (github.com) if needed.
3. Create a NEW PUBLIC repository named gridiron-simulator-online. Do not upload personal files, passwords or API keys.
4. In the repository, choose Add file > Upload files. Upload ALL files from inside this extracted folder (not the folder itself), including render.yaml. Commit changes.
5. Go to dashboard.render.com > New > Blueprint. Connect GitHub, select the new repository, review plan and settings, and deploy. If the free plan is unavailable, do not select a paid plan unless you want charges.
6. Wait for deployment and open the HTTPS *.onrender.com address Render provides. Try Load teams.
7. On iPhone Safari open the same HTTPS URL > Share > Add to Home Screen.

Free hosting can sleep, be limited, or change. Public URL means others can use the simulator; rate limits reduce but do not eliminate abuse. No accounts or private information are stored by this app. Public ESPN feeds are unofficial and may fail. Simulations are experimental, not validated forecasts.

Troubleshooting: Render dashboard > service > Logs. If the site loads but teams do not, check ESPN connectivity and logs. If the deployment is blocked by the free tier, choose another host or ask for assistance; no hosting is provisioned by this ZIP alone.
